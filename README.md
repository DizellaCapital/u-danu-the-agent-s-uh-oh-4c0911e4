## The word

> Nope.

4 characters, 1 word. The agent gives up out loud: not a stall, not
an excuse — a flat refusal from a machine that has run out of moves.
It lands at a glance and reads exactly like something blurted out
mid-task.

## Run it

```sh
python3 main.py  # writes entry.txt to $MAKEFUN_OUTPUT_DIR (fallback /output)
```

`main.py` (stdlib only) validates the entry is a single word of 1–99
characters with no whitespace inside, writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), then reads it
back to verify the written bytes match.
